# Kutlwano Take Portfolio

Professional portfolio website for Kutlwano Take, a Full-Stack and Cloud Engineer based in Johannesburg.

Live site: `https://kutlwano-portfolio.vercel.app`

## Overview

This portfolio highlights production-focused engineering work across AWS serverless architecture, modern frontend development, infrastructure as code, and Python analytics. The site is intentionally lightweight and hand-coded with static assets so it loads quickly, deploys cleanly, and is easy to maintain.

## Featured Sections

- Hero section with a clear engineering value proposition and direct calls to action
- Selected projects with live demos, source links, and technology breakdowns
- Skills and certifications organized by frontend, cloud, backend, and tooling
- About section focused on delivery, ownership, and end-to-end product execution
- Contact section for hiring managers, collaborators, and clients

## Tech Stack

- HTML5
- CSS3
- Vanilla JavaScript
- Responsive layout and progressive enhancement
- Vercel for deployment

## Project Highlights

- `AfriClimate Analytics Platform` - AI-powered climate intelligence product built with Python, Dash, CHIRPS data, and AWS-native analytics services
- `TshidiAI` - AI service-business workspace for quotes, proposals, agreements, payments, and revenue workflows
- `SpendGuard` - serverless expense and budget tracker using React, TypeScript, Cognito, Lambda, DynamoDB, and AI integrations

## Local Development

Because this is a static site, local development is straightforward:

```bash
git clone https://github.com/Kutlwano-Take/kutlwano-portfolio.git
cd kutlwano-portfolio
```

Then open `index.html` directly in a browser or serve the project with your preferred static server.

## Deployment

The site is deployed on Vercel. Pushing updates to the connected branch is enough to publish the latest version.
