AfriClimate Analytics Lake - Climate Intelligence Platform

Production-ready climate analytics platform for Southern Africa with a serverless AWS data pipeline and live Dash application. It ingests CHIRPS climate data into S3, processes it with Lambda, catalogs data in Glue, and serves analytics through Athena with an interactive 5-module dashboard for drought, water security, climate risk, community impact, and carbon insights. Deployed on Render with Gunicorn and a fallback dataset mode for reliable public demo access.

Python 3.11 Dash Plotly AWS S3 AWS Lambda AWS Glue Amazon Athena Boto3 Pandas Render Gunicorn CHIRPS Data
